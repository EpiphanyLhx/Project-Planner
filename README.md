# 研途 · Project Planner

原生 macOS 考研每日打卡应用，使用 SwiftUI 构建，数据全部存储在本地 UserDefaults，无需联网即可使用。支持满负荷 / 底线双模式、周日专项安排、AI 长期任务拆分、任务批量导入和桌面悬浮便签。

## 功能特性

- **每日任务打卡**：内置考研复习模板（数学 / 408 专业课 / 英语 / 睡前复盘），一键勾选完成
- **双模式切换**：满负荷模式（约 9.5 小时）与底线模式（4 小时），按日期独立记忆
- **周日专项**：自动隐藏英语任务，替换为数学错题回看与下周规划
- **凌晨 4:00 学习日边界**：熬夜学习到凌晨 4 点前仍算前一天，4 点后自动开启新一天
- **考研倒计时**：侧边栏实时显示距离考试天数，可自由选择考试年份
- **模块与自定义任务**：创建学习模块，在模块下添加小任务，支持多日期批量创建
- **任务导入**：从 UTF-8 文本或 JSON 文件批量导入任务
- **AI 长期任务拆分**：接入 OpenAI 兼容接口，将大任务拆成每日可执行计划，支持图片附件和规划记录回看
- **桌面悬浮便签**：置顶悬浮窗口显示今日任务，不打断学习节奏
- **本地持久化**：所有数据存储在 UserDefaults，无需账号、无需联网

## 安装与运行

### 方式一：从源码运行（开发调试）

使用 Xcode 打开 `Package.swift`，选择 `ProjectPlanner` scheme 后点击运行。

也可以在终端直接执行：

```sh
swift run ProjectPlanner
```

### 方式二：构建并安装 .app

项目根目录提供了构建脚本，会编译 Release 版本、打包为 `研途.app`、签名并安装到 `~/Applications`：

```sh
./build_app.sh
```

构建完成后，可在「启动台」或 `~/Applications` 中找到「研途」并打开。

> 脚本使用 `codesign --sign -` 进行 ad-hoc 签名，首次打开时若 macOS 提示无法验证，可在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 用户使用手册

### 界面概览

应用主窗口采用三栏布局：

| 区域 | 位置 | 内容 |
|------|------|------|
| 侧边栏 | 左侧 | 应用名称、考研倒计时、当前模式与今日完成进度 |
| 日期选择栏 | 主区域顶部 | 连续 7 天日期切换，左右箭头翻页，日历图标回到今天 |
| 任务面板 | 主区域 | 当日进度环、任务模块列表、完成横幅 |
| 工具栏 | 窗口顶部 | 悬浮便签、AI 拆分、导入任务、添加模块、AI 设置、删除计划 |

### 考研倒计时

侧边栏顶部显示距离考研的剩余天数。

- **默认考试日期**：所选年份的 12 月 19 日
- **切换考试年份**：点击倒计时右上角的年份下拉菜单，选择目标年份（当前年份至当前年份 +10）
- 倒计时数字每天自动更新，过了考试日期后显示为 0

### 每日打卡

1. 主面板中每个任务左侧有一个方形复选框，点击即可标记完成 / 取消完成
2. 任务完成后标题会显示删除线并变灰
3. 模块标题左侧的圆形复选框可一键完成 / 取消该模块下的全部任务
4. 顶部进度环实时显示当日完成比例（已完成数 / 总数）
5. 全部任务完成后，面板顶部会出现绿色完成横幅「今日任务全部完成，辛苦了」，背景也会变为淡绿色

### 模式切换：满负荷 / 底线

在日期栏右侧有一个开关，用于切换当日的学习模式：

- **满负荷模式**（⚡ bolt.fill）：
  - 数学 3 小时（复盘 45min + 看课 75min + 做题 60min）
  - 408 专业课 3.5 小时（滚动复习 60min + 新课 90min + 选择题 60min）
  - 英语 2.5 小时（单词 30min + 阅读精读 120min）
  - 睡前复盘 30 分钟
  - 合计约 9.5 小时

- **底线模式**（🍃 leaf.fill）：
  - 数学 2 小时（保底做题）
  - 408 专业课 2 小时（保底看课 / 复习）
  - 合计 4 小时

> **模式按日期独立记忆**：切换某一天的模式不会影响其他日期。例如周六设为底线模式，周日仍保持满负荷模式。

### 学习日边界：凌晨 4:00

应用以**每天凌晨 4:00** 作为学习日的分界点，而非自然日的 0:00。

- 凌晨 0:00 – 3:59 仍属于前一个学习日
- 凌晨 4:00 起进入新的学习日，默认任务会以未完成状态重新生成

这一设计适配考研党熬夜学习的习惯：晚上学到凌晨 3 点，打卡仍记在当天；睡一觉起来 4 点后，自动开启新一天的计划。

### 周日专项安排

当选中日期为周日时，应用自动调整任务模板：

- **隐藏所有英语任务**（单词、阅读精读）
- **新增「周日专项 · 半天」模块**：本周数学错题回看与下周规划（240 分钟）

此规则在满负荷和底线模式下均生效。

### 模块管理

模块是任务的分组容器，对应一个学习科目或复习阶段。

**添加模块**：
1. 点击工具栏「+ 添加模块」
2. 输入模块名称（如「数学强化」「政治冲刺」）
3. 在月历中选择一个或多个执行日期（点击日期切换选中，支持跨月切换）
4. 点击「添加模块」，模块会出现在每个选中日期的任务列表中

**编辑模块**：
1. 点击模块标题右侧的铅笔图标
2. 可修改模块名称
3. 可调整模块下每个任务的预计时长（步进 5 分钟，上限 720 分钟）
4. 底部显示合计时长

**在模块下添加小任务**：
1. 点击模块标题右侧的「+」圆形按钮
2. 填写任务名称、预计时长、执行日期（可多选）、可选时间段
3. 点击「添加小任务」

### 任务管理

**编辑任务**：
- 点击任务行右侧的铅笔图标，或右键任务选择「编辑小任务」
- 可修改：任务名称、预计时长、执行日期（支持多选多天批量复制）、计划时间段
- 时间段与时长联动：修改时长自动更新结束时间，修改结束时间自动更新时长
- 结束时间不得早于开始时间，且不支持跨天（最晚钳制到 23:59）

**删除任务**：
- 点击任务行右侧的垃圾桶图标，或右键任务选择「删除任务」
- 删除内置模板任务后，该任务在当天不会再自动生成；切换到其他日期仍会正常出现

**任务排序**：
- 设有开始时间的任务按时间先后排列
- 未设时间的任务排在有时间的任务之后，按创建顺序排列

### 任务导入

点击工具栏「导入任务」，选择 UTF-8 纯文本文件或 JSON 文件。

**文本格式**：
- `#` 开头的行表示模块名称
- `-` 或 `*` 开头的行表示任务，支持 `- [ ]` / `- [x]` 复选框格式
- 任务名称后用 `|` 分隔并写预计分钟数

示例：

```text
# 数学强化
- [ ] 高数错题 | 45
- 线代练习 | 30
# 英语
阅读一篇 | 60
```

**JSON 格式**：
对象数组，字段为 `module`（模块名）、`title`（任务名，也可用 `task`）、`minutes`（可选，预计分钟数）。

示例：

```json
[
  { "module": "408", "title": "操作系统选择题", "minutes": 50 },
  { "module": "数学", "title": "线代证明题" }
]
```

> 导入的任务会添加到当前选中日期，标记为自定义任务，不受模板重置影响。

### AI 智能任务拆分

将一个长期大任务（如「过完高数强化篇」）自动拆分为每天可执行的小任务。

**首次使用前配置**：
1. 点击工具栏「AI 设置」（齿轮图标）
2. 填写：
   - **API URL**：OpenAI Chat Completions 兼容接口的基础地址，例如 `https://api.deepseek.com`、`https://open.bigmodel.cn/api/paas/v4/`。应用会自动补全 `/chat/completions` 路径；若已填写完整地址则保持不变
   - **API Key**：你的接口密钥，仅存储在本机 UserDefaults
   - **模型名称**：例如 `gpt-4o-mini`、`deepseek-chat`
3. 点击「完成」

**生成计划**：
1. 点击工具栏「AI 拆分长期任务」
2. 在输入框描述学习目标、资料范围和排期偏好（例如「高数强化篇上册，每天上午 3 小时，周末多安排」）
3. 可选：点击回形针添加图片（教材目录、课程表截图等，最多 4 张，单张不超过 10MB），也可直接 `Cmd+V` 粘贴剪贴板图片
4. 调整期望完成天数（1–90 天，可点数字直接输入或用 +/− 调整）
5. 点击发送按钮（或 `Cmd+Return`）
6. AI 返回后显示**排期预览**，按天分组列出任务名称、时长和推荐时间段
7. 可选择开始日期（默认为今天），也可点击任务旁的铅笔图标编辑单个任务的名称、天数、时长和时间段
8. 确认无误后点击「应用」写入任务列表；点击「重新生成」可清空预览重新输入

**规划记录**：
- 每次生成的计划都会自动保存为规划记录（含原始描述、图片和排期）
- 点击 AI 窗口右上角的时钟图标查看历史记录列表
- 记录分为「草稿」（未应用）和「已应用」两种状态
- 右键或进入详情页可「编辑并重新规划」（复用原记录，修改后重新生成）或「删除」
- 删除时可选择「仅删除记录」或「连同已应用的任务一起删除」

> **安全机制**：AI 返回的内容必须是严格符合约束的 JSON 数组，否则不会写入任何任务。请求失败、超时（120 秒）、JSON 格式错误或 API Key 缺失时均会弹出错误提示，不会污染本地数据。

### 悬浮便签

点击工具栏第一个按钮（窗口图标）可显示 / 隐藏桌面悬浮便签。

- 便签显示**今日**全部任务，点击圆形复选框即可打卡，与主窗口实时同步
- 顶部显示日期，拖拽标题栏可移动窗口
- 图钉按钮控制是否**置顶**：置顶时便签悬浮在所有窗口之上（包括全屏应用），取消置顶后变为普通窗口
- 关闭按钮（×）隐藏便签，可在工具栏重新打开
- 窗口大小和位置会自动记忆

### 删除计划

点击工具栏垃圾桶图标，弹出确认对话框：

- **删除当日计划**：清空当前选中日期的所有任务和模块（不可撤销）
- **删除所有计划**：清空全部日期的任务、模块和 AI 长期计划（不可撤销）

> 删除内置模板任务后，切换模式或日期时模板会重新生成；只有「删除所有计划」会清除模板删除记忆。

## 数据存储

所有数据均存储在 macOS UserDefaults 中，对应 `Bundle Identifier` 为 `com.projectplanner.study`。

| 数据 | UserDefaults Key | 说明 |
|------|-----------------|------|
| 任务列表 | `studyTasks` | JSON 编码的 `[StudyTask]` |
| 模块列表 | `studyModules` | JSON 编码的 `[StudyModule]` |
| AI 长期项目 | `largeTaskProjects` | JSON 编码的 `[LargeTaskProject]` |
| 规划记录 | `planningRecords` | JSON 编码的 `[PlanningRecord]` |
| 每日模式 | `studyModesByDay` | 学习日 → 模式的映射 |
| 已删除模板 | `deletedStudyTemplateKeys` | 避免删除的模板任务重新生成 |
| AI 配置 | `ai.apiURL` / `ai.apiKey` / `ai.model` | API 地址、密钥、模型名 |
| 考试年份 | `exam.year` | 倒计时目标年份 |
| 便签置顶 | `isWidgetPinned` | 悬浮便签是否置顶 |

AI 规划记录的图片附件存储在：

```
~/Library/Application Support/ProjectPlanner/PlanningRecords/<记录ID>/
```

```sh
swiftc Sources/ProjectPlanner/AISettings.swift \
  Sources/ProjectPlanner/StudyTask.swift \
  Sources/ProjectPlanner/StudySchedule.swift \
  Sources/ProjectPlanner/StudyDay.swift \
  Sources/ProjectPlanner/TaskImporter.swift \
  Sources/ProjectPlanner/AITaskService.swift \
  Checks/CoreLogicChecks.swift \
  -o /tmp/project-planner-checks
/tmp/project-planner-checks
```

全部通过时输出 `Core logic checks passed (19/19)`。

## 常见问题

**Q：应用打不开，提示「无法验证开发者」？**
A：这是 ad-hoc 签名的正常现象。前往「系统设置 → 隐私与安全性」，向下滚动找到被阻止的应用，点击「仍要打开」。

**Q：凌晨 3 点打卡，任务算在哪一天？**
A：算前一天。应用以凌晨 4:00 为分界，4:00 之前都属于前一个学习日。

**Q：删除了一个默认任务，第二天还会出现吗？**
A：会。模板任务的删除记忆仅对当天生效，切换到其他日期或第二天会重新生成。

**Q：AI 拆分一直失败怎么办？**
A：检查以下几点：① API URL 是否为 OpenAI 兼容地址（需支持 `/chat/completions`）；② API Key 是否正确且有余额；③ 模型名称是否与服务商匹配；④ 网络是否可访问该接口。错误弹窗会显示具体原因。

**Q：数据会同步到云端吗？**
A：不会。所有数据仅存储在本机 UserDefaults 和 Application Support 目录中，卸载应用会一并删除。

**Q：可以修改默认的复习科目和时长吗？**
A：内置模板在 `StudySchedule.swift` 中定义，修改后重新编译即可。也可以通过「添加模块」和「导入任务」创建完全自定义的计划。
